# Camera Landing

Next.js foundation for a premium landing page for outdoor solar security cameras.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

## Asset folders

- `public/media/videos` - hero and product tour videos
- `public/media/images` - stills, posters, and supporting product imagery

## Scripts

```bash
npm run dev
npm run build
npm run lint
```
